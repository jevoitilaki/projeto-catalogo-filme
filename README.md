# Lumina

Catálogo de filmes e séries desenvolvido com React e Tailwind CSS.

## Tecnologias

- React
- Vite
- Tailwind CSS
- React Router

## Funcionalidades

- Navegação entre Início, Filmes, Séries e Minha Lista
- Banners em destaque
- Seções de conteúdo em carrossel
- Header responsivo com menu mobile
- Design escuro e moderno

## Como executar

```bash
npm install
npm run dev
